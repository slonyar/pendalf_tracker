## Описание

Веб-приложение для отслеживания местоположения участников Братства Кольца, разработанное специально для **Пендальфа Серого** (он же **Саша Белый**). Приложение позволяет великому магу следить за передвижениями всех членов Братства в их опасном путешествии по уничтожению супер-мега-зловредного кольца.

## Функциональность для Пендальфа

### Основные возможности:
- ✅ Добавление и управление персонажами Братства (от Фёдора Михайловича до Гиви Зурабовича)
- ✅ Отметки геолокаций с датой, временем и координатами
- ✅ Интерактивная карта для отслеживания всех бойцов
- ✅ Просмотр маршрутов передвижения за любой период
- ✅ Фильтрация по персонажам и временным диапазонам
- ✅ Детальная разведсводка по каждому участнику

### Дополнительные возможности для эффективной координации:
- 📱 Мобильная версия для полевых условий
- 🗺️ Предустановленные локации (от Хоббитании до Мордовии)
- 📊 Аналитика и статистика передвижений
- 🔍 Система поиска и фильтрации данных
- 💾 Экспорт координат для штабных карт
- 🎨 Интуитивный интерфейс в стиле военного планштаба

## Технологический арсенал

- **Серверная часть:** Python 3.11, Flask, SQLAlchemy
- **Клиентская часть:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
- **Картографический модуль:** Leaflet.js с OpenStreetMap
- **База разведданных:** SQLite (полевая версия)
- **Контейнеризация:** Docker для развертывания в любых условиях

## Быстрое развертывание системы

### Автоматическая установка (для штабных условий)

```bash
# Получаем исходный код
git clone <repository-url>
cd fellowship-tracker

# Автоматическая настройка всей системы
make setup

# Загружаем тестовые данные о Братстве
make init-sample-data

# Запуск системы слежения
make dev-with-data
```

### Ручная установка (для полевых условий)

```bash
# Создаем виртуальную среду
python3 -m venv venv

# Активируем среду
source venv/bin/activate  # На macOS/Linux
# venv\Scripts\activate   # На Windows

# Устанавливаем необходимые модули
pip install -r requirements.txt

# Инициализируем базу данных
python -c "from app import app, db; app.app_context().push(); db.create_all()"

# Загружаем тестовые данные Братства (опционально)
python -c "from app import app, db, init_sample_data; app.app_context().push(); init_sample_data()"

# Запускаем систему слежения
python app.py
```

### Контейнерное развертывание

```bash
# Сборка образа
make docker-build

# Запуск в контейнере
make docker-run

# Альтернативно через docker-compose
docker-compose up --build
```

## API для автоматизации

### Разведывательные endpoints:

- `GET /api/characters` — Полный список отслеживаемых персонажей
- `GET /api/locations` — Все зафиксированные местоположения
- `GET /api/locations?character_id=1` — Маршрут конкретного бойца
- `GET /api/locations?start_date=2024-01-01&end_date=2024-12-31` — Данные за период

### Примеры запросов:

```bash
# Получить всех членов Братства
curl http://localhost:5000/api/characters

# Проследить маршрут Фёдора Михайловича
curl "http://localhost:5000/api/locations?character_id=1"

# Разведданные за последнюю неделю
curl "http://localhost:5000/api/locations?start_date=2024-12-12T00:00:00"
```

## Принятые тактические решения

### Архитектура системы
- **Монолитная структура** — обеспечивает быстрое развертывание в полевых условиях
- **Локальная база SQLite** — автономность и независимость от внешних серверов
- **Серверный рендеринг** — быстрая загрузка даже при слабом соединении

### Картографические решения
- **Leaflet.js** — легкая библиотека для работы с картами
- **OpenStreetMap** — бесплатные детальные карты всего мира
- **Цветовое кодирование** — каждый боец имеет свой цвет на карте
- **Предустановленные точки** — ключевые локации Средиземья уже внесены

### Безопасность и надежность
- **CSRF защита** — предотвращение атак через подложные формы
- **Валидация входных данных** — на сервере и в браузере
- **Защищенные заголовки** — предотвращение XSS-атак
- **Обработка ошибок** — система продолжает работать при сбоях

### Производительность
- **Оптимизированные запросы** — использование JOIN и индексов
- **Кэширование статики** — быстрая загрузка интерфейса
- **Сжатие ответов** — экономия трафика
